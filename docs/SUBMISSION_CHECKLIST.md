# Hackathon Submission Checklist

## Factory
- [ ] BAND Desktop room visibly recorded.
- [ ] At least 3 distinct coding-agent seats.
- [ ] Every seat uses a generic, workload-agnostic mandate.
- [ ] Agent handoffs produce inspectable artifacts.
- [ ] End-to-end run is reproducible.

## Workload
- [ ] Tablekeeper service starts from a clean container.
- [ ] Concurrency attack is executable.
- [ ] Idempotency attack is executable.
- [ ] Timezone attack is executable.
- [ ] Invalid-input/transaction behavior is covered.
- [ ] Resource and concurrency limits are documented from the actual final run.

## Evidence
- [ ] Public GitHub repository.
- [ ] Multiple meaningful stages/commits.
- [ ] Initial adversarial result captured.
- [ ] Repair/regression result captured when applicable.
- [ ] Independent verifier result captured.
- [ ] Final walkthrough video includes BAND Desktop room and finished workload.

Do not mark a box complete without evidence.
